# motorola-mfp-68901

The Motorola MC68901 multi-function peripheral: GPIO, four timers, a vectored interrupt controller and a USART.

| Crate | Registry |
|---|---|
| [`emu198x-motorola-mfp-68901`](crates/emu198x-motorola-mfp-68901) | [crates.io](https://crates.io/crates/emu198x-motorola-mfp-68901) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Atari ST.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
